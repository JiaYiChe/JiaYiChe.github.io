Task definition

Code + CSV

Binary label on date t: 1 if next-session return > +1%, else 0.

Class 0 is not “down.” It is everything except a large up-move: down days, flat days, and small gains. A plain up/down label would be ~54.5% / 45.5% — this threshold is what created the imbalance.
